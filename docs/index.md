## About this site

This is the public companion site for **FORGE EVOLVE for TMPC** - 577 Industries' U.S. Navy SBIR
Phase I work under topic **DON26BZ01-NV013** ("AI-Assisted Modernization and Optimization of Theater
Mission Planning Center (TMPC) Software"). It mirrors the repository's own Markdown verbatim, so every
claim here is the claim in the repo - no new assertions are introduced.

Start with the **[5-minute Reviewer Onramp](reviewers.md)**, then the
**[Proposal Companion](companion.md)** (each claim mapped to the file/test that backs it). The
**[Artifacts & Claims](artifacts.md)** registry deep-links each claim to the release-tagged source.

!!! warning "Preliminary, surrogate-based results"
    Every metric on this site is measured on the **synthetic, unclassified** surrogate in the
    repository and is **preliminary** - not validated against government TMPC code and not validated
    by the Navy. No Navy endorsement is implied. See **[Honesty & Exclusions](honesty.md)**.
